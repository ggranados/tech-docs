# Tech Docs

A breadth-first IT knowledge repository and training path for software architects — clear overviews of the concepts that come up in system design, with links to official documentation for going deeper. Not a tutorial series; a map of the territory.

Built for architect candidates preparing for the role, and useful as a quick reference for anyone who wants a fast, accurate refresher on a topic without wading through a full course.

## [Get Started →](get-started.md)

The [Get Started](get-started.md) page is the full contents map — every topic covered, organized by category, with a filter box to jump straight to what you're looking for.

You can also contribute by submitting pull requests with additional content, corrections, or improvements.
