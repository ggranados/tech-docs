# Phase 0 Research: Data Structures Content

## Decision: 5 pages covering 10 bullets via grouping (Linear Structures, Trees, + 3 standalone)

**Rationale**: Array/Linked List/Stack/Queue are commonly taught and compared as one family (sequential access patterns); Binary Tree/AVL Tree/Trie are all tree variants best explained together with a shared "what makes a tree a tree" framing before differentiating. Hash Table, Heap, and Graph are conceptually distinct enough to warrant their own pages.

## Decision: Surface `docs/img/big-o-notation.png` in the Linear Structures page as a shared complexity-class reference

**Rationale**: The image was merged to `develop` in a prior, separate piece of work but never linked from any page — an orphaned asset. Rather than leaving it unused, referencing it once (where Big-O is first introduced in this new category) gives it a home without duplicating the same image across all 5 pages.
