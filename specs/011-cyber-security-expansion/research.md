# Phase 0 Research: Cyber-Security Fundamentals Expansion

## Decision: Group by architect-relevance tier (priority/secondary/operational)

**Rationale**: An architect makes design decisions informed by Cryptography, Secure Coding, Web App Security, Security Architecture, and Data Privacy far more often than they run incident response or threat intel programs — those are real but more operational/GRC-heavy concerns, worth covering (no dead bullets) but appropriately lighter.

## Decision: Web Application Security cross-links rather than duplicates AuthN/AuthZ content

**Rationale**: `docs/pages/ws-and-api-design/authn-and-authz/` already has strong OAuth/JWT/SAML/SSO coverage. Web App Security should reference these for the authn/authz slice of OWASP Top 10 rather than re-explaining them.
