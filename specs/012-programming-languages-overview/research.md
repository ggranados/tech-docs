# Phase 0 Research: Programming Languages Overview Pages

## Decision: Flat single-page-per-language, not a Java-style directory tree

**Rationale**: Java's depth is explicitly called out as the exception in the source spec, not the bar to match — this asymmetry (Java: ~25 pages, every other language: 0) was the actual problem being fixed. A flat overview page per language keeps the fix proportionate.
